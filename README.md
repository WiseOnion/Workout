# Physique Transformation Program

**Goal:** Transform from ~230 lbs / ~35% body fat → ~165 lbs / ~10–12% body fat.  
Build a lean, athletic fighter-physique with visible V-taper, shoulder caps, and full musculature — while developing real calisthenics skills from pull-ups to muscle-ups, handstands, and front lever progressions.

**Gym:** Planet Fitness — 4803 Ramsey St, Fayetteville, NC 28311 (24 hours)  
**Starting point:** ~230 lbs, ~33–38% body fat  
**Target:** ~165 lbs, ~10–12% body fat  
**Timeline:** 18–24 months at full execution

## Quick Reference

- **Best training times:** 5–8am or 9pm–midnight (avoid 4–7pm peak)
- **Daily protein minimum:** 185–200g
- **Caloric target:** 2,500–2,700 calories/day (500–700 deficit)
- **No running until 200 lbs** — incline walking and rowing only
- **Track pull-ups weekly** — single best indicator the program is working
